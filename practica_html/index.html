Contenido incrustado en HTML

En esta página se muestran ejemplos reales de cinco etiquetas: <img>, <iframe>, <embed>, <object> y <video>.

1. Imagen — <img>

Esta etiqueta permite mostrar una imagen en la página.

2. Página incrustada — <iframe>

Permite mostrar otra página HTML dentro de esta misma página.

3. Archivo incrustado — <embed>

Sirve para insertar un recurso externo, como un documento PDF.

Abrir el PDF si no se muestra

4. Recurso externo — <object>

Permite incluir archivos de diferentes tipos. Aquí aparece una ilustración SVG.

5. Vídeo — <video>

Con esta etiqueta insertamos un vídeo con controles para reproducir, pausar y ajustar el volumen. Necesita conexión a Internet para cargar el archivo de ejemplo.
